# EL3313 - Proyecto 1
## Whack-a-mole híbrido FPGA / lógica discreta

En el siguiente repositorio se encontrará disponible acerca del proyecto para el curso _Taller De Sistemas Digitales_ del Instituto Tecnológico de Costa Rica.

En este repositorio encontrarás dentro docs lo siguiente:
  * _diseño.md:_ Este es un README el cual es ficha descriptiva y de primeros diseños del trabajo.
  * _informe.md:_ Este es una ficha técnica acerca del trabajo con análisis teórico, simulaciones, testbenches y concluisiones, entre otros.
  * _ImagenesDocu:_ Folder con figuras utilizadas.
  * _SubsistemaControl:_ Código para la funcionalidad del proyecto con código en SystemVerilog y constraints de Vivado para su generación de Bitstream exitosa para Basys 3 en arquitectura Artix-7 (Modelo del dispositivo utilizado: _xc7a35ticpg236-1L_).
